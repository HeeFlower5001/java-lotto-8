# java-lotto-precourse
## 과제(프로그램) 설명
해당 과제(프로그램)는 로또 발매기를 구현했습니다.  
사용자가 입력한 구입 금액에 맞게 로또를 자동으로 발행하고,  
당첨 번호와 보너스 번호를 입력합니다.  
입력받은 번호와 비교하여 수익률/당첨 개수를 계산합니다.

- 로또
  - 1장의 가격은 천원이다. (1,000원 단위가 아닐 경우 예외)
  
  - 번호
    - 숫자 범위는 1 ~ 45
    - 중복되지 않는 6개의 번호와 보너스 번호 1개
    - 숫자 범위나 번호 개수가 맞지 않을 경우 예외를 던진다.

- 당첨
  - 1등: 6개 번호 일치
  - 2등: 5개 번호 + 보너스 번호 일치
  - 3등: 5개 번호 일치
  - 4등: 4개 번호 일치
  - 5등: 3개 번호 일치  
  
  
- 모든 예외 상황은 '[ERROR]' 메시지로 표시하고, 잘못된 입력은 다시 받는다.
